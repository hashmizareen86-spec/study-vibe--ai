# 🎓 StudyVibe AI — Placement & Visual Study Companion

An AI-powered placement preparation platform that converts complex study PDFs into interactive 3D animated Hinglish & English Flashcards and real-time Placement Quizzes.

## ✨ Features
- **Dual Language Support:** English & Hinglish toggles.
- **3D Animated Flashcards:** Visual CSS flip-card experience.
- **Placement Quiz Arena:** Instant feedback with gamified rewards.
- **PDF Processing:** Automated text analysis using Google Gemini.
